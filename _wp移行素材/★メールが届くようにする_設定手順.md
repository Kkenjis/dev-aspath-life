# ★ 申込メールが確実に届くようにする設定

作成日：2026年8月19日／所要 **約20分**

---

## 0. いま何が起きているか

初回体験フォームは、送信されると**2通のメール**を出します。

| | 宛先 | 目的 |
|---|---|---|
| ① 通知メール | 山口様（`aspathlife@gmail.com`） | 申込があったことを知る |
| ② 控えメール | **申込者の方**（Gmail・docomo・au など様々） | 受け付けた安心感を与える |

**現在、この2通とも届きません。** テスト送信でも届きませんでした。

### 原因

```
送信元メールアドレス： aspathlife@gmail.com
実際に送っているサーバー： エックスサーバー
```

**`gmail.com` を名乗りながら、Gmail とは無関係のサーバーから送っている**状態です。
Gmail をはじめ各社は、なりすまし対策としてこうしたメールを**受信箱にも迷惑メールにも入れず破棄**します。
エラーが出ないので気づけません。

> ⚠ これは**②の控えメールでも同じ**です。申込者が「送ったのに何も来ない」と感じ、
> 不信感につながります。**①より深刻かもしれません。**

---

## 1. 解決方針（おすすめ）

**送信元を、自社ドメインのメールアドレスに変えます。**

```
変更前： aspathlife@gmail.com  ← 他社のドメインなので拒否される
変更後： info@aspath-life.com   ← 自社ドメインなので正規の送信元として扱われる
```

`aspath-life.com` はエックスサーバーで管理されているため、
**送信元をこのドメインにするだけで、正規の送信者として認められます。**

### 山口様の受け取り方は変わりません

- 通知メールは**これまでどおり `aspathlife@gmail.com` に届きます**（宛先は変えません）
- 変えるのは「差出人」だけです

### むしろ良くなる点

| | 変更前 | 変更後 |
|---|---|---|
| 差出人の見え方 | `aspathlife@gmail.com` | **`info@aspath-life.com`** |
| 申込者の印象 | 個人のGmail | **事業者らしい** |
| 届く確率 | ほぼ届かない | 高い |

---

## 2. 手順

### 2-1. メールアドレスを作る（5分・エックスサーバー側）

エックスサーバーのサーバーパネル → **メールアカウント設定** → `aspath-life.com` を選択 → **メールアカウント追加**

| 項目 | 入力例 |
|---|---|
| メールアカウント | `info`（→ `info@aspath-life.com` になります） |
| パスワード | 推測されにくいものを設定し、**控えておく** |
| 容量 | 既定のままでOK |

- [ ] `info@aspath-life.com` を作成
- [ ] パスワードを控えた

> 💡 既に `aspath-life.com` のメールアドレスをお持ちなら、それを使っても構いません。
> その場合はこの手順を飛ばしてください。

### 2-2. WordPress側の設定（10分）

**WP Mail SMTP → 設定**

**① 送信元を変える**

| 項目 | 設定 |
|---|---|
| 送信元メールアドレス | **`info@aspath-life.com`** |
| 送信元メールアドレスを強制使用 | **オン** |
| 送信者名 | `ASPATH（アスパス）` |
| 送信者名を強制使用 | オン |

**② メーラーを設定する**

「メーラー」の一覧から **「その他のSMTP」** を選び、エックスサーバーの情報を入力します。

| 項目 | 設定 |
|---|---|
| SMTPホスト | `sv****.xserver.jp`（サーバーパネルで確認できます） |
| 暗号化 | **SSL** |
| SMTPポート | **465** |
| 認証 | **オン** |
| ユーザー名 | `info@aspath-life.com` |
| パスワード | 2-1で設定したもの |

- [ ] 設定して保存

> **SMTPホストの調べ方**：エックスサーバーのサーバーパネル → メールアカウント設定 →
> 該当ドメイン → 「メールソフト設定」に記載されています。

### 2-3. テストする（5分）

**WP Mail SMTP → ツール → メールテスト**

- [ ] `aspathlife@gmail.com` へ送信 → **受信箱に届く**
- [ ] ご自身のアドレスへ送信 → 届く
- [ ] **キャリアメール**（docomo / au / SoftBank）へ送信 → 届く

> キャリアメールは最も厳しいので、ここまで通れば安心です。

### 2-4. フォームから実際に申し込んでみる

`https://aspath-life.com/development/taiken-2026as9y/`

- [ ] 送信後、緑の「お申し込みを受け付けました。」が出る
- [ ] **①通知メール**が `aspathlife@gmail.com` に届く
- [ ] **②控えメール**が入力したアドレスに届く
- [ ] 管理画面「初回体験の申込」にも記録されている
- [ ] 通知メールに返信すると**申込者宛**になる
- [ ] テスト分の申込を削除

## 3. ほかの選択肢

| 方法 | 手間 | 到達率 | 備考 |
|---|---|---|---|
| **自社ドメイン＋エックスサーバーSMTP**（上記） | 20分 | 高い | **おすすめ。追加費用なし** |
| SendLayer などの送信専門サービス | 10分 | 最も高い | 月200通まで無料。外部サービスの登録が必要 |
| Gmailを正式に接続 | 30分 | 最も高い | 差出人を `aspathlife@gmail.com` のままにできる。Google Cloud の設定が必要で難しい |

**差出人をどうしても `aspathlife@gmail.com` にしたい場合のみ**、3番目を検討してください。
そうでなければ、上の手順が最も簡単で確実です。

---

## 4. 申込が消えることはありません

**メールが届かなくても、申込データは必ず WordPress に保存されます。**

管理画面 → **「初回体験の申込」** で、全項目を確認できます。
メールの設定を直すまでの間も、ここを見れば申込を取りこぼしません。

> この設計にしてあるのは、まさに今回のような事態に備えるためです。

---

## 5. 本番でも同じ設定が必要です

この設定は**ステージング環境のもの**です。
本番に初回体験フォームを設置する際、**本番のWordPressでも同じ設定**を行ってください。

- [ ] 本番の WP Mail SMTP にも同じ設定を入れる
- [ ] 本番でもテスト送信して確認する
