# ★ プランの吹き出し ── 文章の差し替え手順

作成：2026年8月26日　／　**いまの文章は仮です**

---

## 1. どう動くか

「プランと料金」ページの各プランカードに
**「このプランの内容を見る」** ボタンを付けました。

押すと、3枚のカードのすぐ下に**吹き出し**が開き、
三角の先が押したカードを指します。

- もう一度押す／×を押す／Escキー／外側をクリック　で閉じます
- 3つのプランそれぞれに別の内容が入ります
- スマホでは**押したカードのすぐ下**に開きます（幅いっぱい）
- PCでは3枚のカードの下に開き、三角が押したカードを指します

---

## 2. 文章を差し替える場所

**`price.html` の中**、各カードの `<div class="pc-detail">` の中です。

```
detail-plan8  … 月8回コース
detail-plan4  … 月4回コース
detail-plan2  … 月2回コース
```

`Ctrl + F` で **`pc-detail`** を検索すると3か所見つかります。

### いまの構成（1つ分）

```html
<div class="pc-detail" id="detail-plan4" hidden>
  <p class="pd-lead">※ここは仮の文章です。…</p>   ← 差し替え時に削除
  <ul class="pd-list">
    <li><b>週1回の対面</b>で運動を習慣に…</li>      ← 箇条書き（増減自由）
    <li>…</li>
  </ul>
  <p class="pd-fit"><b>こんな方に</b>　…</p>        ← 下部の帯
</div>
```

| クラス | 見え方 |
|---|---|
| `pd-lead` | うすいオレンジの帯（**仮の注記用。本番では消してください**） |
| `pd-list` | 箇条書き。`<li>` を増やせばそのまま増えます |
| `pd-fit` | 下部のベージュの帯。「こんな方に」の1行 |
| `<b>…</b>` | 太字。強調したい語に付けます |

---

## 3. 差し替えたあと

```
1. price.html を保存
2. テーマを作る.ps1 を実行
3. 外観 → テーマ → アップロード →「既存のものを置き換える」
4. Super Page Cache → Purge Cache
```

---

## 4. 山口様に文章をお願いするとき

**この形でいただければ、そのまま流し込めます。**

```
【月4回コース】
・（箇条書き1つめ）
・（箇条書き2つめ）
・（箇条書き3つめ）
こんな方に：（ひとこと）
```

3プラン分そろえば、こちらで反映します。**1プランずつでも構いません。**

---

## 5. 技術的なメモ

- ボタン：`.pc-more`（`aria-expanded` を持ち、開くとオレンジ＋「×」に変化）
- 吹き出し：`#pc-pop`（`price-grid` の直後。中身は `.pc-detail` から差し込む）
- 三角の位置：JSが押されたカードの中心を計算し `--tail-x` に設定
- JS：`js/services-05.js`（「プランと料金」ページでのみ読み込み）
- 他ページでは `if(!pop) return;` で何もしません
