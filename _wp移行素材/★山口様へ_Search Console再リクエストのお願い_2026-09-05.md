## 4. よくあるご質問

**Q. 1日に何件までできますか？**

正確な上限は公表されていませんが、**10件前後**が目安です。
上限に達すると「割り当てを使い切りました」と出ます。その場合は翌日にお願いします。

**Q. 何度も押すとペナルティになりませんか？**

なりません。順位が下がることもありません。押しすぎても、早くはならないだけです。

**Q. 押したのに変わりません。失敗ですか？**

いいえ。**リクエストは「順番待ちの列に並ぶ」操作**です。
Googleが実際に見に来るのは、数時間〜数日後になります。

```
　［リクエストを押す］
　　　↓　ここで数時間〜数日の待ち時間
　［Googleが見に来る］　← この瞬間のページが登録されます
```

**Q. 他のページはリクエストしなくていいですか？**

はい。サイト名が変わったので全ページのタイトルが変わっていますが、
**トップページをリクエストすれば、Googleは他のページも順に見直します。**
急ぎでなければ、この4件で十分です。
