# ★ コラムのコメント機能 導入手順

作成日：2026年8月19日／所要 **約20分**／山口様のご要望による追加

---

## 0. 何をするか

現行サイトのブログでコメントに反響があるため、**新サイトのコラムでも同じように
コメントを受け付けられる**ようにしました。

**現行サイトと同じ使い勝手にしています。**

| | 現行サイト | 新サイト |
|---|---|---|
| 入力項目 | お名前【必須】／メール【必須】／サイト／本文 | **同じ** |
| メールアドレス | 公開されない | **同じ** |
| 返信（スレッド） | できる | **同じ** |
| アイコン | Gravatar | **同じ** |
| 迷惑コメント対策 | Akismet | **同じ** |

**見た目だけをサイトの意匠に合わせました。** 文字を16px以上にし、入力欄とボタンを
大きめにしています（シニアの方が操作しやすいように）。

## 1. 本番のコメントはどうなるか ★ご安心ください

**現在いただいている2件のコメントは、そのまま残ります。**

| | 内容 |
|---|---|

> コメントより前だったためです。**本番には影響しません。**

## 2. テーマを更新する（5分）

4. キャッシュを削除 → **Ctrl+F5**

- [ ] バージョンが **`1.1.20260819.1324` 以降**になっている

## 3. コメントを受け付ける設定にする（10分）

### 3-1. 全体の設定

**設定 → ディスカッション**

| 項目 | 設定 | 理由 |
|---|---|---|
| 新しい投稿へのコメントを許可 | **チェックを入れる** | 今後のコラムで自動的に有効になる |
| コメントの投稿者は名前とメールアドレスの入力必須 | **チェックを入れる** | 現行サイトと同じ |
| コメントを○階層までのスレッド形式にする | **チェック・5階層** | 返信ができるように |
| **コメントの手動承認を必須にする** | **チェックを入れる**（推奨） | 公開前に必ず目を通せる |
| 以前コメントが承認されたコメントの投稿者 | チェックを外す | 上と合わせて全件承認制に |
| コメントが投稿されたとき（メール通知） | **チェックを入れる** | 気づけるように |
| コメントがモデレーション待ちの場合 | **チェックを入れる** | 同上 |

- [ ] 上記を設定して保存

> 💡 **手動承認をおすすめする理由**：健康・医療に関わるサイトのため、
> 事実と異なる情報や不適切な内容が、承認なしに公開されることを避けられます。
> 承認は管理画面から1クリックです。

### 3-2. 既存の記事でコメントを開く

**新しい設定は「これから書く記事」にしか適用されません。** 既存の記事は個別に開きます。

投稿一覧 → 対象の記事を選択 → **一括編集** → 「コメント」を **許可** → 更新

- [ ] コラム4本すべてでコメントを許可
- [ ] お知らせ3本は**どうするか決める**（下記）

> **お知らせ記事のコメントについて**
> お知らせ（営業案内・キャンペーン）にコメント欄が必要かはご判断ください。
> **コラムだけに付ける**方がすっきりします。閉じる場合は一括編集で「不許可」に。

## 4. 表示を確認する（5分）

- [ ] コラム記事を開くと、本文の下に**コメント欄**が出る
- [ ] 「お名前」「メールアドレス」「コメント」の入力欄がある
- [ ] 「メールアドレスが公開されることはありません」と書かれている
- [ ] **スマホでも入力欄がはみ出さない**
- [ ] 実際に1件テスト投稿してみる
  - [ ] 「承認待ちです」と表示される
  - [ ] 管理画面に通知が来る
  - [ ] 承認すると記事に表示される
  - [ ] **テスト投稿を削除する**
- [ ] 「返信する」を押すと、フォームがそのコメントの下に移動する

## 5. 迷惑コメント対策

**Akismet が既に有効**なので、追加の作業は不要です。

- [ ] Akismet の API キーが設定されている（プラグイン → Akismet で確認）

> 手動承認と併用すれば、迷惑コメントが公開されることはまずありません。

---

## 6. 運用のしかた（山口様へお伝えする内容）

| | 内容 |
|---|---|
| **コメントが来たら** | メールで通知が届きます |
| **公開するには** | 管理画面 → コメント → 「承認」を押す |
| **返信するには** | 同じ画面で「返信」。スタッフからの返信には**「スタッフ」の印**が付きます |
| **迷惑コメント** | Akismet が自動で振り分けます。念のため時々ご確認ください |
| **コメントを閉じたい記事** | その記事の編集画面 → 右サイドバー →「ディスカッション」→ チェックを外す |

---

## 7. 補足：デザイン面で工夫した点

- コメント1件ずつを**白いカードに枠線と影**を付けて表示（お知らせ一覧と同じ意匠）
- スタッフからの返信には**「スタッフ」バッジ**を表示。誰の発言か一目で分かります
- 投稿ボタンは記事内のCTAと**同じオレンジ**。迷わず押せるように
- 「承認待ちです」を**投稿者本人には表示**。送れたかどうか分からない不安をなくします
- スマホでは入力欄とボタンを**画面幅いっぱい**に。押し間違いを減らします
