## 1. Redirection プラグインを入れる（5分）

1. プラグイン → **新規追加**
2. 検索窓に `Redirection` と入力
3. 作者が **John Godley** のものを選ぶ（同名の別物に注意）
4. **今すぐインストール** → **有効化**

### 初期設定ウィザード

有効化すると設定ウィザードが出ます。

- [ ] 「**Basic setup**」で次の2つに**チェックを入れる**
  - `Monitor permalink changes in WordPress posts and pages`（投稿のURL変更を自動追跡）
  - `Keep a log of all redirects and 404 errors`（転送と404の記録を残す）
- [ ] 「IP Logging」は **No IP logging**（個人情報を残さない）
- [ ] Continue → Finish setup

> ログを残しておくと、**設定漏れのURLが後から分かります**。仮公開のあいだ 404 の記録を
> ときどき見ると、想定外の旧URLを拾えます。

## 2. 4本を登録する（10分）

**ツール → Redirection → Add new redirection**

各行、次の2つを入れて **Add Redirect** を押すだけです。

| # | Source URL（転送元） | Target URL（転送先） |
|---|---|---|
| 1 | `/for-parkinsons-disease/` | `/パーキンソン病とアスパスの歩み方/` |
| 2 | `/パーキンソン病の方へ/` | `/パーキンソン病とアスパスの歩み方/` |
| 3 | `/for-stroke/` | `/about/` |
| 4 | `/blog/` | `/column/` |

- [ ] 4本を登録
- [ ] 一覧で4本すべてが **Enabled**（有効）になっている

> 💡 **`/development/` は付けません。** Redirection はサイトのルートからの相対パスで
> 判定するので、この書き方でステージングでも本番でもそのまま動きます。
>
> 💡 種別は既定の **301 Moved Permanently** のままでOKです。

### ⚠ 日本語URLがうまく動かない場合

ブラウザは日本語URLを内部で英数字に変換して送ります（`パーキンソン病の方へ` →
`%e3%83%91%e3%83%bc%e3%82%ad...`）。Redirection が日本語のまま照合できないときは、
**変換後の形でもう1本追加**してください。

**転送元（`/パーキンソン病の方へ/` の変換後）**

```
/%e3%83%91%e3%83%bc%e3%82%ad%e3%83%b3%e3%82%bd%e3%83%b3%e7%97%85%e3%81%ae%e6%96%b9%e3%81%b8/
```

**転送先（`/パーキンソン病とアスパスの歩み方/` の変換後）**

```
/%e3%83%91%e3%83%bc%e3%82%ad%e3%83%b3%e3%82%bd%e3%83%b3%e7%97%85%e3%81%a8%e3%82%a2%e3%82%b9%e3%83%91%e3%82%b9%e3%81%ae%e6%ad%a9%e3%81%bf%e6%96%b9/
```

- [ ] 日本語のままで動いた（→ 追加不要）
- [ ] 動かなかったので変換後の形も追加した

- [ ] 4本すべて転送された

> `/blog/` の404が消えることが、いちばん分かりやすい成功の目印です。
