## フェーズ4：画像をメディアライブラリへ登録

1. 外観 → テーマ → 新規追加 → **テーマのアップロード**

> テーマの中に画像54点が同梱されています。**固定ページ側は画像アップロード不要**です。

### 4-2. 投稿用の画像だけをメディアに登録

|---|---|---|

> **ファイル名は用途がわかる形に統一済み**です。メディアライブラリで名前順に並べると、記事ごとにまとまります。

## フェーズ5：コンテンツ投入

### 5-1. カテゴリーを作る（最初にやる）

投稿 → カテゴリー

| 名前 | スラッグ | 用途 |
|---|---|---|
| お知らせ | **`info`** | キャンペーン等のお知らせ |
| コラム | **`column`** | 読み物記事 |

> ⚠ **お知らせのスラッグは必ず `info`** にしてください。TOPのお知らせ枠がこのスラッグを見て記事を拾っています。

- [ ] 「未分類」を使わない（既定カテゴリーを「コラム」に変更しておくと安全）

### 5-2. 固定ページを作る

固定ページ → 新規追加。**本文は空でOK**（テンプレートが中身を持っています）。
タイトルとスラッグだけ設定してください。

| タイトル | スラッグ | 自動で当たるテンプレート |
|---|---|---|
| ASPATHについて | `about` | `page-about.php` |
| プランと料金 | `services` | `page-services.php` |
| 交通アクセス | `access` | `page-access.php` |
| お問い合わせ | `contact` | `page-contact.php` |
| よくあるご質問 | `faq` | `page-faq.php` |
| プライバシーポリシー | `privacy` | `page-privacy.php` |
| 特定商取引法に基づく表記 | `tokushoho` | `page-tokushoho.php` |
| サイトマップ | `sitemap` | `page-sitemap.php` |
| ホーム | `home`（任意） | `front-page.php` |
| お知らせ | `info` | ※§5-4参照 |
| ブログ | `blog` | ※§5-4参照 |

- [ ] 設定 → 表示設定 → **ホームページ**＝「ホーム」／**投稿ページ**＝「ブログ」

### 5-3. 投稿（コラム3本・お知らせ1本）を作る

**カテゴリー「コラム」**

| タイトル | スラッグ | 公開日 | アイキャッチ |
|---|---|---|---|
| パーキンソン病とアスパスの歩み方 | `パーキンソン病とアスパスの歩み方` | 2026-07-19 | `column-parkinson-thumbnail.webp` |
| アスパスのオンライントレーニングがおすすめ！ | `onlineaspath` | 2026-07-28 | `column-onlineaspath-thumbnail.webp` |
| アスパススタジオでの対面トレーニング | `taimentraining` | 2026-08-03 | `column-taimentraining-thumbnail.webp` |

**カテゴリー「お知らせ」**

| タイトル | スラッグ | 公開日 | 備考 |
|---|---|---|---|
| 営業開始キャンペーン｜初回体験（90分）が期間限定 半額4,400円 | `campaign` | 2026-07-01 | **「先頭に固定表示」にチェック**（＝重要なお知らせ） |

> 既存2記事（`taimentraining` / `onlineaspath`）は**本番に既にあるスラッグ**です。同じスラッグで作ることで、リダイレクトが不要になります。

**本文の入れ方**

各記事の本文は dev の該当HTMLからコピーします。ブロックは**見出し／段落／画像／引用**の4つだけで組めます。

- [ ] `column-parkinson.html` → パーキンソン病の記事
- [ ] `onlineaspath.html` → オンラインの記事
- [ ] `taimentraining.html` → 対面の記事
- [ ] `news-campaign.html` → キャンペーンのお知らせ

**注意：本文中で `Shift＋Enter` の手動改行は入れないでください。** 自動で文節折り返しが効くため、手動改行はスマホで不自然な位置に切れます。

### 5-4. お知らせ一覧・コラム一覧

- **`/blog/`** … 「投稿ページ」に設定したページ。`home.php` が全投稿を一覧表示
- **`/info/`** … お知らせだけの一覧。カテゴリー「お知らせ」のアーカイブ（`archive.php`）が使われます
  - 固定ページ `info` を作る場合は、**カテゴリーアーカイブと重複しないよう**どちらか一方に統一してください（推奨：固定ページは作らず、カテゴリーアーカイブ `/category/info/` をメニューの「お知らせ」に割り当て、必要ならスラッグを `/info/` に見せる設定）

### 5-5. メニュー

外観 → メニュー

**グローバルメニュー**：TOP ／ ASPATHについて ／ **お知らせ** ／ コラム ／ プランと料金 ／ アクセス ／ お問い合わせ

**フッター**：上記＋プライバシーポリシー／特定商取引法／サイトマップ

- [ ] 順番が dev と一致していること

## フェーズ6：フォーム（SureForms）

詳細は `SureForms項目設計表.md` の **§8（最新・LINE一本の構成）** を参照。

### 6-1. お問い合わせページ（フォームは不要）

**2026-08-15 変更：お問い合わせは公式LINE一本に統一しました。**

- [ ] `/contact/` に**フォームは設置しない**（LINE登録ボタンと電話番号のみ。テンプレート側に組み込み済み）
- [ ] 作成が必要なフォームは **初回体験の1本だけ**（下記 6-2）

### 6-2. 初回体験フォーム（限定公開）

- [ ] 固定ページを新規作成し、**ページテンプレート＝「初回体験フォーム（限定公開）」**を選択
- [ ] スラッグは**推測されにくい文字列**にする（例：`taiken-2026a9k`）
- [ ] noindex を設定（SureRank）／メニュー・サイトマップに載せない
- [ ] 項目：お名前／フリガナ／生年月日／**メール【必須】**／電話／ご住所／どなた／診断名／困りごと／きっかけ／メッセージ
- [ ] **メールを2通**送る設定
  - 山口様宛：件名 `【初回体験】ASPATH お申し込み／{お名前}様`
  - 申込者宛（控え）：件名 `【ASPATH】初回体験のお申し込みを受け付けました`

### 6-3. 到達性の確認

- [ ] WP Mail SMTP が設定済み
- [ ] reCAPTCHA v3 / Akismet を有効化
- [ ] **テスト送信**：Gmail・キャリアメールの両方で受信を確認（迷惑メール振り分けも見る）

### 6-4. 限定URLの共有

- [ ] 発行したURLを山口様へ連絡 → 公式LINEの自動応答／リッチメニューに掲載
