## 2. やること（優先順）

### 🔴 ① Search Console にサイトマップを送る（10分・効果大）

**新サイトになったことをGoogleに伝える作業です。これをしないと反映が遅れます。**

```
1. https://search.google.com/search-console にアクセス
2. aspath-life.com のプロパティを開く
   （未登録なら「プロパティを追加」→ ドメイン or URLプレフィックス）
3. 左メニュー「サイトマップ」
4. 次のURLを入力して「送信」
```

```
sitemap_index.xml
```

> ⚠️ **`wp-sitemap.xml` ではありません。**
> `★次にやること.md` に `wp-sitemap.xml` と書いていましたが、
> 実測の結果、このサイトが実際に使っているのは
> **`https://aspath-life.com/sitemap_index.xml`** でした。**こちらが正しい**です。

**続けてやること**

```
5. 上部の検索窓に https://aspath-life.com/ を入力 → 「インデックス登録をリクエスト」
6. 主要5ページで同じことを繰り返す
   /about/ /services/ /column/ /access/ /contact/
```

**数日後に確認すること**

```
・「ページ」→ エラーに /blog/ が出ていないか
  （blog は column に変わったため）
・「ページ」→ 未登録のページが増えていないか
```

### 🟡 ④ フォームがサイトマップに載っている

サイトマップに `post-type-sureforms_form-sitemap-1.xml` が含まれています。
**フォームの部品が検索対象になっている**状態で、不要です。

```
SEOプラグインの設定 → XMLサイトマップ
→ 投稿タイプ「sureforms_form」のチェックを外す
```

> 実害は小さいですが、**中身の薄いページが多いとサイト全体の評価が下がる**ため、
> 外しておくのが無難です。

> **コメントがつく記事は検索でも強くなります。**
> いただいた質問をそのまま次の記事のテーマにするのが、最も効率のよい方法です。

## 3. やらなくてよいこと（かえって危険）

| | 理由 |
|---|---|
| 被リンクの購入 | **ペナルティ対象。** 順位が落ちます |
| キーワードの詰め込み | 読みにくくなり評価も下がります |
| 「1位保証」をうたう業者 | 保証は原理的に不可能です |
| AIで大量生成した記事 | 中身が薄いと逆効果。**実体験に基づく記事のほうが強い**です |

## 4. 効果が出るまでの目安

| 時期 | 起きること |
|---|---|
| 1〜2週間 | Googleが新サイトを読み直す。**一時的に順位が下がることがあります（正常）** |
| 1か月 | 元の水準に戻る。ビジネスプロフィールの効果が出始める |
| 3か月〜 | 記事の蓄積が効いてくる |

> **公開直後の順位変動で慌てないでください。**
> サイトを作り替えた後は必ず起きる現象で、放置すれば戻ります。
> ここで設定をいじり回すのが**最も悪手**です。
