# ★ 固定ページを山口様が編集できるようにする（試行：ASPATHについて）

作成：2026年8月23日　／　**10月のクローズに向けた引継ぎ対応**

---

## 1. 何をするのか

固定ページの本文は、これまで**テーマの中**にHTMLとして埋め込まれていました。
そのため山口様は編集画面から直せず、**引継ぎ後に手が出せなくなる**状態でした。

これを、**WordPressの固定ページ編集画面で直せる形**に移します。

```
これまで： テーマの page-about.php に本文がある  → 山口様は直せない
これから： WordPressの固定ページに本文がある      → 山口様が直せる
```

**見た目は1pxも変わりません。** HTMLの中身をそのままブロックに置き換えているためです。

### 編集できるようになる範囲

| | 文字数 | 割合 |
|---|---|---|
| **山口様が直せる部分** | 3,792字 | **81%** |
| 装飾・図（触らない部分） | 851字 | 18% |

**触らない部分**は次の5か所です。デザインが複雑なため、
崩れないよう「カスタムHTML」として固めてあります。ここは**依頼で直します**。

```
・ASPATHの頭文字（A S P A T H の一覧）
・特徴3つのカード（症状に特化／専用プラン／オンライン）
・「自分らしい人生」の大きな帯
・4つの理念の図／各章の写真とキャプション
```

```

見出し   6個   ← 直せる
囲み枠  13個
装飾     9個   ← 触らない
```

## 3. 実施手順

> ⚠️ **順番が重要です。** 逆にするとページが一時的に真っ白になります。

### ① バックアップを取る（5分）

```
All-in-One WP Migration → エクスポート → ファイル
```

### ② 固定ページに本文を貼る（10分）

```
1. 固定ページ → 「ASPATHについて」を編集
2. 右上の ⋮（縦三点） → コードエディター
3. 中身が空であることを確認
4. 下のファイルの中身を全選択してコピーし、貼り付ける
     _wp移行素材/★固定ページ_貼り付け用/ASPATHについて_貼り付け用.txt
5. 右上の ⋮ → ビジュアルエディター に戻す
6. 「このブロックには問題があります」の警告が出ていないことを確認
7. 【更新】
```

**この時点ではまだ見た目は変わりません。** 古いテーマが本文を無視しているためです。

### ③ テーマを入れ替える（5分）

```
外観 → テーマ → 新規追加 → テーマのアップロード
→ aspath-theme.zip（v1.1.20260823 以降）
→ 「既存のものを置き換える」
```

### ④ キャッシュを消して確認（5分）

```
Super Page Cache → Purge Cache → Ctrl + F5
https://aspath-life.com/about/
```

### ⑤ 確認すること

```
□ 見た目が以前と同じ
□ 「English」を押すと英語に切り替わる
□ プランと料金ページの「3つの芯」リンクから飛べる
□ スマホでも崩れていない
```

## 4. うまくいかないときの戻し方

| 症状 | 対処 |
|---|---|
| **ページが真っ白** | 本文の貼り付けが空。②をやり直す |
| **見た目が崩れた** | 外観 → テーマ → 1つ前のテーマに戻す。**すぐ元に戻ります** |
| **ブロックに警告が出る** | 貼り付けが途中で切れている。全選択して貼り直す |
| **英語が出なくなった** | ②で貼った内容が古い。ファイルを再取得して貼り直す |

**テーマを戻せば、その場で元の表示に復帰します。** データは失われません。

---

## 5. 【重要】この後の運用が変わります

**「ASPATHについて」の本文は、もう `about.html` ではありません。**

| | これまで | これから |
|---|---|---|
| 本文の置き場所 | `about.html` | **WordPressの固定ページ** |
| 直す人 | 開発担当 | **山口様** |
| `about.html` の役割 | 本文の正本 | **元の姿の記録（参照用）** |

> ⚠️ **`about.html` を直しても、サイトには反映されません。**
> 逆に、`build_wp_theme.py` の `EDITABLE_PAGES` から `about.html` を外すと
> **山口様の編集が上書きされて消えます。** 外さないでください。

この注意はテーマの `page-about.php` の先頭にもコメントで書いてあります。

## 6. 残りのページをどうするか

今回は**ASPATHについての1枚だけ**を試しました。
問題がなければ、同じ手順で他のページも移せます。

| ページ | 段落数 | 難易度 |
|---|---|---|
| プランと料金 | 34 | 中（料金表が装飾込み） |
| 対面トレーニング | 82 | **低（文章中心・作業しやすい）** |
| オンライン | 54 | **低** |
| アクセス | 11 | 低 |
| よくある質問 | 10 | 中（開閉部分が装飾） |
| TOP | 36 | **高（装飾が最も多い）** |

**おすすめの順番**：対面トレーニング → オンライン → アクセス → プランと料金 → よくある質問 → TOP

変換コマンド

```
python tools/html2blocks.py taimentraining.html > 貼り付け用.txt
```

そのうえで `build_wp_theme.py` の `EDITABLE_PAGES` にファイル名を足します。

## 7. 仕組みのメモ（開発担当向け）

- 変換器：`tools/html2blocks.py`
- CSSはスラッグで読み込まれる（`is_page('about')` → `about.css`）ため、
  **テンプレートを変えてもデザインは崩れない**
- 見出しの `id` は `anchor` 属性として保持 → ページ内リンクが生きる
- `data-en` / `data-en-html` は**内側の span に移動**している
  （タグに見慣れない属性が付くとブロックが「無効」と判定されるため。
  　切替スクリプトは `[data-en]` を探すだけなので動作は変わらない）
- グループブロックは `wp-block-group__inner-container` を挟まない形で保存しているため、
  **出力HTMLは書いたとおりそのまま**
