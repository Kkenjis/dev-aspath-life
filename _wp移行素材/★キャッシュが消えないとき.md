# ★ 更新したのにサイトが変わらないとき

2026年8月26日　／　**実際に発生した事象と、その切り分け方**

---

## 1. 今回起きたこと

テーマは最新（`1.1.20260826.2332`）が入っているのに、
「プランと料金」ページのスマホ対応が反映されていませんでした。

**原因はページのキャッシュです。** サイトのファイル自体は正しく新しくなっていました。

### 実測した証拠

| URL | 配信元 | 中身 |
|---|---|---|
| `/services/` | `x-wp-spc-disk-cache: HIT` | **8月23日のHTML**。プランの吹き出しのJSが入っていない |
| `/services/?x=123` | `x-wp-spc-disk-cache: BYPASS` | **最新のHTML**。正しく動く |

**クエリ（`?x=123`）を付けるとキャッシュを通らないため、新しいページが出ます。**

---

## 2. まず確認する方法（30秒）

スマホで、末尾に `?x=1` を付けて開いてください。

```
https://aspath-life.com/services/?x=1
```

**ここで正しく動けば、サイトの中身は正常です。** 残っているのはキャッシュだけです。

---

## 3. 直し方

### ① Super Page Cache でパージ

```
管理画面 → Super Page Cache → Purge Cache
```

**押したあと、Activity Log の一番上に新しい行が増えることを確認してください。**
増えていなければ、押せていません。

### ② それでも消えないとき

Activity Log に次の行が出ている場合、プリロード（先読み）が止まっています。

```
Unable to start the preloader. Another preloading process is currently running.
```

このときは次を試してください。

```
1. Super Page Cache → Settings
2. キャッシュを一度 無効化 → 保存
3. もう一度 有効化 → 保存
```

これで溜まっていたファイルが作り直されます。

### ③ 最後の手段

サーバーパネルのファイルマネージャーで、キャッシュの保存先フォルダを空にします。
**場所が分からない場合は触らず、ご連絡ください。**

---

## 4. なぜ気づきにくいのか

| | |
|---|---|
| CSS・JSファイル | URLに `?ver=` が付くので、**更新すると必ず新しくなります** |
| **ページのHTML** | URLが同じままなので、**古いものが出続けます** |

**「CSSは新しいのに、ページが古い」という状態が起こり得ます。**
今回がまさにそれでした。

> 見分け方：`?x=1` を付けて直れば、キャッシュが原因です。

---

## 5. 更新作業のたびに行うこと

```
1. テーマをアップロード
2. Super Page Cache → Purge Cache
3. Activity Log に新しい行が増えたか確認   ← ここが抜けやすい
4. ?x=1 付きのURLで確認
5. 通常のURLでも確認
```

**4と5の両方を見るのが確実です。**
