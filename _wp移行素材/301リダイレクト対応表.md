# 301リダイレクト対応表

新サイト（現在制作中のデザイン）へ差し替える際、**旧URLの評価と流入を引き継ぐ**ための対応表です。

> ⚠ 旧サイト（`aspath-life.com`）は外部から本文を取得できなかったため、**旧URL欄は実機で吸い出して確定**させてください（手順は §1）。新URL欄はこちらで確定済みです。

---

## 1. 旧URLの洗い出し（作業当日いちばん最初に実施）

差し替え前でないと取得できません。**必ずテーマ差し替え前に**実施してください。

| 方法 | 手順 | 備考 |
|------|------|------|
| ① WP管理画面 | 固定ページ一覧・投稿一覧を開き、各行の「表示」URLを控える | いちばん確実。**これだけでほぼ足ります** |
| ② サイトマップ | `https://aspath-life.com/wp-sitemap.xml` または SureRank のサイトマップを開く | 一覧をまとめてコピーできる |
| ③ Search Console | 「ページ」レポート → 過去16か月のURLをエクスポート | **検索流入が実際にあるURL**が分かる＝優先度判定に最適 |
| ④ アナリティクス | 人気ページ上位30件 | ①②で漏れたURLの拾い上げ |

洗い出した全URLを、下の §3 の表に貼り付けてください。

### 現時点で判明していること
- 正規ドメインは **`www.aspath-life.com`**（`aspath-life.com` へのアクセスが www 付きへ転送される）。
  → 新サイトでも **www有り／無しの正規化**を維持し、どちらか一方に統一すること。
- 常時SSL（`https://`）で稼働中。**httpsのまま維持**。

### C. 新規ページ（旧サイトに無い＝リダイレクト対象外）

`/access/`・`/faq/`・`/privacy/`・`/tokushoho/`・`/sitemap/` は新規のため転送不要。ただし公開後にSearch Consoleの404ログを監視し、旧サイトに隠れURL（noindex等）があれば個別に追加する。

★★★＝検索流入・広告導線があるページ（最優先）／★★＝通常／★＝低

### 併せて設定しておくパターン

| パターン | 例 | 対応 |
|---------|-----|------|
| 旧テーマの投稿ID URL | `/?p=123` | 各記事の新URLへ301 |
| カテゴリ／アーカイブ | `/category/news/` | `/news/` へ301 |
| 末尾スラッシュ揺れ | `/about` | `/about/` へ301（WPが自動処理） |
| www有無 | `aspath-life.com/...` | `www.aspath-life.com/...` へ統一（現行仕様を維持） |
| 大文字URL | `/About/` | 小文字へ301 |
| 該当なし | 上記以外の旧URL | **トップへ一括転送はしない**。404のままにするか、最も近いページへ個別に301 |

> 「全部トップへ転送」は検索評価が引き継がれず、ユーザーも迷子になります。**1対1で近いページへ**が原則です。

## 4. 設定方法（推奨：Redirection プラグイン）

1. プラグイン **Redirection** を新規インストール・有効化
2. 「転送ルール」→「新規追加」
   - ソースURL：旧URL（例：`/staff/`）
   - ターゲットURL：新URL（例：`/about/`）
   - HTTPコード：**301（恒久的に移動）**
3. §3 の表を上から順に登録
4. 「ログ」タブで404の発生を監視 → 出てきたURLを追加登録

### .htaccess で書く場合（サーバー負荷が軽い）
```apache
# ASPATH 旧URL → 新URL（301）
Redirect 301 /staff/ https://www.aspath-life.com/about/
Redirect 301 /reserve/ https://www.aspath-life.com/contact/
```
※ `# BEGIN WordPress` ブロックの**外側・上**に記述。編集前に必ず `.htaccess` のバックアップを取得。

## 5. 公開直後のチェック

- [ ] §3 の全URLをブラウザで開き、**新URLに一発で飛ぶ**（多段転送になっていない）
- [ ] ステータスコードが **301**（302になっていないか）
- [ ] リダイレクトループが発生していない
- [ ] Search Console でサイトマップを再送信
- [ ] Redirection の「ログ」で404を1〜2週間監視し、随時追加
- [ ] Googleビジネスプロフィール・SNSプロフィール・広告のリンク先URLを新URLに更新
- [ ] 名刺・チラシ等の印刷物に旧URLが載っていないか確認（載っていればそのURLは**恒久的に**301を残す）

---

## 6. 注意

- **リダイレクト設定は本番切替と同時**に有効化。ステージング段階では設定しても効きません。
- 旧サイトのデータは、**クローズ後も一定期間は削除せず保持**（合意済み）。復旧が必要になった場合の備えです。
- 301は最低でも**1年間**は維持してください（検索エンジンの評価移行に時間がかかるため）。
