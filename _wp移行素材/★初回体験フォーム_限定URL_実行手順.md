# ★ 初回体験フォーム（限定URL）実行手順

作成日：2026年8月17日／所要 約40分（うち待ち時間・テスト含む）
対象：`https://aspath-life.com/development/`（ステージング）

---

## 0. 何をするのか

**devで作ったフォームは、そのままではWordPressで送信できませんでした。** 原因を修正済みです。

devの `trial-entry.html` は静的サイト用（Netlify）のフォームで、送信先が
`action="trial-entry.html"` になっていました。WordPressに置くと
**画面は正常に見えるのに、送信ボタンを押しても誰にも届かない**状態になります。
気づきにくく、申込を丸ごと失う類の不具合です。

そこで、**見た目・項目・文言は一切変えずに**、送信の仕組みだけをWordPress用に作り直しました。

| | 変更前（dev） | 変更後（WordPress） |
|---|---|---|
| 送信先 | Netlify（存在しない） | **自分自身にPOST → PHPが処理** |
| 保存 | なし | **WordPress内に自動保存** |
| メール | なし | **2通送信**（山口様＋申込者への控え） |
| 入力のやり直し | 全部消える | **入力内容が残る** |
| 検索エンジン | — | **noindex＋サイトマップ除外** |

> 💡 **SureFormsは使いません。** 既にあるフォームをそのまま活かすほうが、
> デザインが崩れず、項目の並びも山口様が確認済みのものを維持できます。

## 1. 全体の流れ（申込者から見た動き）

```
① 申込者が公式LINEを友だち追加
        ↓
② 自動応答メッセージが届く（この中に限定URLを載せる）
        ↓
③ 申込者がURLをタップ → フォームに記入して送信
        ↓
④ 山口様に通知メール ＋ 申込者に控えメール（48時間以内にご連絡と記載）
        ↓
⑤ 管理画面「初回体験の申込」にも自動で残る
```

**このページはサイトのどこからもリンクしません。** メニュー・サイトマップ・フッターにも出ません。
URLを知っている人だけが開ける状態（限定公開）です。

## 2. テーマを更新する（3分）

1. **GitHub Desktop で Pull origin**
2. **「テーマを作る.ps1」を右クリック →「PowerShell で実行」**
   → `_wp移行素材/aspath-theme.zip` ができ、**バージョンが画面に表示されます**
3. 外観 → テーマ → 新規追加 → **テーマのアップロード** → zipを選択
4. 「**既存のものを置き換える**」を選択
5. Super Page Cache のキャッシュを削除 → **Ctrl+F5**

実行ポリシーで止まる場合は、PowerShellを開いて下の1行を貼ってください。

```powershell
powershell -ExecutionPolicy Bypass -File ".\テーマを作る.ps1"
```

- [ ] 外観 → テーマ のバージョンが、**スクリプトが表示したバージョンと一致**している
      （`1.1.20260817.2007` 以降）

> バージョンが上がっていなければ、アップロードが完了していません。
> スクリプトが表示する値とWordPress側の値を見比べるのが、いちばん確実な判定方法です。

## 4. キャッシュから除外する（3分）★重要

**この作業を飛ばすと、送信時に「送信が無効になりました」というエラーが出ます。**

フォームには改ざん防止用の使い捨ての符号（nonce）が埋め込まれています。
ページがキャッシュされると**古い符号が配られ続け**、正しく入力しても弾かれます。

テーマ側で自動除外する処理を入れてありますが、キャッシュは二重にかかっているため
プラグイン側でも設定しておくと確実です。

**Super Page Cache**

1. 設定 → Super Page Cache → **Cache** タブ
2. 「**Never cache the following pages**」（キャッシュしないページ）に、作成したページを追加
3. 変更を保存 → **キャッシュをパージ**

- [ ] 除外設定を追加した
- [ ] キャッシュをパージした

> Cloudflare側のキャッシュも使っている場合は、同じURLを除外に追加してください。

## 5. メールが届く状態か確認する（5分）

**WP Mail SMTP** が設定済みかを先に確認します。ここが未設定だと、
**保存はされるがメールだけ届かない**状態になります。

1. WP Mail SMTP → 設定 → **送信元メールアドレス**が設定されている
2. WP Mail SMTP → **ツール → メールテスト** → 山口様のアドレスへテスト送信
3. 届いたことを確認

- [ ] テストメールが届いた

> 届かない場合は、フォームより先にこちらを解決してください。
> **申込自体は管理画面に保存されるので失われません**が、気づくのが遅れます。

## 8. 限定URLの置き場所

### 8-0. ⚠ 仮公開の段階では、公式LINEにまだ載せないでください

これがこのフォームで**唯一の重大な注意点**です。

いまのURLは **ステージング**のものです。

```
仮公開中（いま）： https://aspath-life.com/development/taiken-2026as9y/
本番切替後（9月）： https://aspath-life.com/taiken-2026as9y/
```

**ステージングのURLを本番の公式LINEに載せると、実際のお客様がステージングに申し込みます。**
ステージングのデータは9月の切替では**本番へ移しません**（方式B）。
つまり、**その申込は誰にも気づかれないまま消えます。**

| 段階 | 限定URLをどこへ | 目的 |
|---|---|---|
| **仮公開（いま）** | **山口様へ直接お伝えするだけ**（メール／チャット） | 中身と送信の確認 |
| **本番切替後（9月）** | **公式LINEのあいさつメッセージ**（§8-1） | 実運用 |

- [ ] 仮公開の段階では、**LINEには設定しない**
- [ ] 山口様へURLをお伝えし、「**確認用です。LINEにはまだ載せないでください**」と添える
- [ ] 既にLINEへ設定してしまっている場合は、**いったん外す**

> サイトのどこからもリンクしていないので、URLを伝えなければ誰も到達しません。

### 8-1. 【本番切替後に実施】友だち追加時のあいさつメッセージ

WordPress側の設定ではありません。

> ⏸ **この作業はフェーズ9（9月の本番切替）で行います。**

## 9. 運用上の注意（山口様へお伝えする内容）

| 項目 | 内容 |
|---|---|
| **申込の確認方法** | メールが届きます。あわせて管理画面「**初回体験の申込**」にも自動で残ります |
| **メールが届かないとき** | 管理画面の「初回体験の申込」を見れば内容は分かります。**申込が消えることはありません** |

| **通知先アドレスを変えたいとき** | テーマの作り直しが必要です。ご連絡ください（現在 `aspathlife@gmail.com`） |
| **個人情報** | 生年月日・住所を含みます。**WordPressのログインパスワードは強固なものに**してください |

## 11. うまくいかないときの見分け方

| 症状 | 原因 | 対処 |
|---|---|---|
| **フォームが出ずに白紙／別の見た目** | テンプレートを選んでいない | 固定ページ編集 → 右サイドバー → テンプレート＝「初回体験フォーム（限定公開）」 |

| **フォームが二重に出る** | 固定ページの本文に何か書いている | 本文を空にする |
| **送信後も何も起きない** | テーマが古い（更新前） | 外観 → テーマ のバージョンを確認（`1.1.20260817.2007` 以降） |
