# ★ 初回体験フォームを本番に先行設置する手順

作成日：2026年8月17日／所要 **約30分**／対象：**`https://aspath-life.com`（本番）**

---

## 0. なぜこうするのか

公式LINEに載せるURLは、**最初から本番のURLであるべき**です。
ステージングのURL（`/development/` が入ったもの）を載せると、次の問題が起きます。

- お客様に `/development/` という不自然なURLが見える
- **9月の切替でLINEのURLを差し替える作業が必要**になる（忘れると申込が届かない）
- 申込がステージングのDBに入り、本番へは移らない

そこで、**フォームのページだけ**を本番に先行設置します。

| | 内容 |
|---|---|
| **公開URL** | `https://aspath-life.com/taiken-2026as9y/` |
| **サイトの見た目** | **変わりません**（旧テーマのまま。フォームは自己完結ページ） |
| **本番に追加するもの** | **プラグイン1つだけ**（固定ページも作りません） |
| **9月の切替時** | **何もしなくてよい**。URLも挙動もそのまま |
| **やめたいとき** | プラグインを停止するだけ。URLは404に戻り、痕跡は残りません |

> 💡 **固定ページを作らない設計**にしています。URLを直接受け取る方式なので、
> 固定ページ一覧にも、サイトマップにも、メニューにも一切現れません。

## 1. 事前確認（5分）

- [ ] 本番のバックアップを取得（プラグイン追加だけですが、習慣として）
- [ ] 本番の管理画面にログインできる
- [ ] `_wp移行素材/aspath-trial-form.zip` が手元にある（無ければ下のコマンド）

```powershell
powershell -ExecutionPolicy Bypass -File ".\テーマを作る.ps1"
python build_trial_plugin.py
```

> `テーマを作る.ps1` を先に実行してください。プラグインはテーマの生成物を材料にするので、
> **フォームの中身がステージング版と食い違うことがありません。**

### 通知先メールアドレスの確認 ★重要

プラグインに **`aspathlife@gmail.com`** が埋め込まれています。

- [ ] このアドレスで合っている（違う場合は**設置前に**ご連絡ください。作り直します）

## 2. プラグインを入れる（5分）

1. 本番の管理画面 → **プラグイン → 新規追加**
2. **プラグインのアップロード** → `aspath-trial-form.zip` を選択
3. **今すぐインストール** → **プラグインを有効化**

- [ ] プラグイン一覧に「**ASPATH 初回体験フォーム**」が**有効**で表示される

### URLを登録し直す（念のため）

- [ ] **設定 → パーマリンク** を開いて、何も変えずに「**変更を保存**」

> 有効化時に自動で登録されますが、環境によって反映が遅れることがあります。
> この操作をしておくと確実です。

## 3. 表示を確認する（5分）

- [ ] `https://aspath-life.com/taiken-2026as9y/` を開く
- [ ] フォームが表示される（ASPATHのロゴ・クリーム色の背景・オレンジの送信ボタン）
- [ ] **サイトの他のページが今までどおり**であることを確認（TOP・`/about/` など）

> ⚠ **「ページが見つかりません」と出る場合**は §7 を見てください。ほぼパーマリンクの再保存で直ります。

### キャッシュから除外する ★これを飛ばすと送信でエラーが出ます

フォームには使い捨ての符号（nonce）が埋まっています。ページがキャッシュされると
**古い符号が配られ続け**、正しく入力しても弾かれます。

- [ ] **Super Page Cache** → 「キャッシュしないページ」に `/taiken-2026as9y/` を追加
- [ ] Cloudflare を使っている場合、同じURLをキャッシュ除外に追加
- [ ] キャッシュをパージ

> プラグイン側でもキャッシュ禁止の指示を出していますが、二重にかかっているので
> 両方で設定しておくのが確実です。

## 4. 送信テスト（10分）★必須

**ここを飛ばすと「画面は出るのに届かない」に気づけません。** 必ず実施してください。

### 4-1. メールの土台を確認

- [ ] **WP Mail SMTP → ツール → メールテスト** で山口様のアドレスへ送信 → 届く

> 届かない場合は、フォームより先にこちらを解決してください。
> （申込自体は管理画面に保存されるので失われませんが、気づくのが遅れます）

### 4-2. 実際に申し込んでみる

本当に申し込むつもりで入力して送信します。

- [ ] 送信後に**緑の「お申し込みを受け付けました。」**が出る
- [ ] **山口様宛に通知メール**が届く（件名 `【初回体験】ASPATH お申し込み／◯◯様`）
- [ ] **入力したアドレスに控えメール**が届く（件名 `【ASPATH】初回体験のお申し込みを受け付けました`）
- [ ] 控えメールに「**48時間以内にご連絡いたします**」と書かれている
- [ ] 管理画面の左メニューに「**初回体験の申込**」が出て、いま送った分が入っている
- [ ] 通知メールに**そのまま返信すると申込者宛**になる（宛先を見るだけでOK）

### 4-3. エラー側も試す

- [ ] お名前を空にして送信 → 赤い枠で「お名前をご入力ください。」と出る
- [ ] そのとき、**他の入力内容が消えていない**

### 4-4. 2種類のメールアドレスで

キャリアメールは迷惑メール判定されやすく、本番で実際に困る箇所です。

- [ ] Gmail に届いた
- [ ] キャリアメール（docomo / au / SoftBank など）に届いた

### 4-5. 後片付け

- [ ] **テスト分の申込を削除**（「初回体験の申込」→ ゴミ箱へ）

## 5. 検索エンジンに出ないことを確認（3分）

- [ ] ページのソースに `<meta name="robots" content="noindex,nofollow,noarchive">` がある
- [ ] `https://aspath-life.com/wp-sitemap.xml` と `sitemap_index.xml` に**このURLが無い**

> プラグイン側で `noindex` を出力し、HTTPヘッダーでも指定しています。

## 7. うまくいかないときは

| 症状 | 原因 | 対処 |
|---|---|---|
| **「ページが見つかりません」** | URLの登録が反映されていない | 設定 → パーマリンク → 変更を保存（何も変えずに） |
| **「送信が無効になりました」** | ページがキャッシュされ、古い符号が配られている | §3のキャッシュ除外 → パージ |
| 送信は成功するがメールが来ない | WP Mail SMTP 未設定／迷惑メール判定 | §4-1。**申込は管理画面に残っています** |
| フォームの見た目が崩れている | CSSが読めていない | プラグインを一度停止→有効化。ブラウザで Ctrl+F5 |
| **サイト全体が真っ白になった** | 想定外の競合 | プラグインを**停止**すれば即座に元に戻ります（下記） |

### 元に戻す方法

**プラグイン → ASPATH 初回体験フォーム → 停止**

これだけです。URLは404に戻り、サイトには何の影響も残りません。
（管理画面からプラグイン画面が開けない場合は、FTPで
`wp-content/plugins/aspath-trial-form` フォルダの名前を変えれば停止扱いになります）

> 💡 **保存済みの申込は消えません。** プラグインを停止しても、
> 再度有効化すれば「初回体験の申込」に元のデータが表示されます。

## 8. 9月の本番切替との関係

| | 対応 |
|---|---|
| **このプラグイン** | **そのまま有効のままにしてください**。停止する必要はありません |
| **LINEのURL** | **変更不要**。すでに本番URLです |
| テーマ側のフォーム機能 | プラグインが有効なら、テーマ側は自動的に何もしません（二重に動きません） |
| 固定ページ「初回体験 お申し込み」 | **作らないでください**。プラグインがURLを持っています |

> `★フェーズ9_本番切替_方式B_実行手順.md` の §3-8（フォームのページを作る）と
> §5-1（LINEのURL差し替え）は、**この手順を実施した時点で不要になります。**

## 9. ステージング側はどうなるか

ステージングのフォーム（`/development/taiken-2026as9y/`）は**そのまま残します**。

| | 用途 |
|---|---|
| `…/development/taiken-2026as9y/` | **確認用**。デザインや項目を見直すときに使う |
| `…/taiken-2026as9y/`（本番） | **実運用**。LINEから来たお客様が使う |

- [ ] 山口様には「**LINEに載っているのは本番のURL**」とお伝えする
- [ ] ステージングのURLは**お客様には案内しない**
