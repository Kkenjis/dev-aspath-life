## はじめに ─ 検索結果に古い情報が出ている件

いただいた画面（「鹿児島 アスパス」の検索結果）に**旧サイトの情報が混ざっている**のは、
**サイト側の設定ミスではありません。**

実際にサイトが今返している中身を確認しました。

| | サイトが今返している中身 | Googleが画面に出している中身 |
|---|---|---|
| タイトル | 鹿児島のパーキンソン病・脳卒中専門トレーニングスタジオ｜ASPATH（**新**） | ASPATH・アスパス：鹿児島のパーキンソン病と脳卒中専門の…（**旧**） |
| 説明文 | 鹿児島のパーキンソン病・脳卒中専門トレーニングスタジオASPATH…（**新**） | アスパスは鹿児島のパーキンソン病と脳卒中専門の…（**旧**） |

**サイトはすでに新しくなっています。** Googleが前回見に来たときの「写し」を
表示し続けているだけです。

Googleは変更を自動で即座に反映しません。**もう一度ページを見に来る（再クロール）**
まで、古い写しを出し続けます。**通常は数日〜2週間程度**です。

> **ドメインが変わっていないこと自体は、まったく問題ありません。**
> むしろ、これまで積み上げた評価をそのまま引き継げるので有利です。

## ご質問への回答

### Q1. ロゴ（検索結果に出る丸いアイコン）は更新されますか？

**いいえ。今回のSEO設定では変わりません。別の場所で管理されています。**

あの丸いアイコンは「**ファビコン（サイトアイコン）**」と呼ばれるもので、
今回私が設定したメタディスクリプションやタイトルとは、まったく別の仕組みです。

**現状を確認したところ、すでに設定済みで、正常に配信されています。**

| 項目 | 状態 |
|---|---|
| 設定 | あり（WordPressのサイトアイコン） |
| サイズ | 192×192px ／ 32×32px |
| Googleの要件（48pxの倍数・正方形） | ✅ 満たしています |
| 配信状態 | ✅ 正常（エラーなし） |

つまり、**今のロゴがこれからもそのまま使われます。**
画面に写っているアイコンで問題なければ、**対応は不要**です。

**変更したい場合の場所：**
管理画面 → 外観 → カスタマイズ → サイト基本情報 → 「サイトアイコン」

> ロゴを差し替えても、Googleの表示が変わるまでは同じく数日〜数週間かかります。

## 点検で見つかった不具合と、その対応

「SEO設定は万全か」とのご依頼でしたので、あらためて全体を点検しました。
**3件の問題が見つかり、うち2件はすでに直しました。**

### ① 構造化データの画像が「存在しない場所」を指していた ─ 修正済み

Googleに事業内容を伝えるデータの中で、写真の場所を
`wp-content/uploads/studio.jpg` と指定していましたが、
**このファイルは存在しませんでした（404エラー）。**

Googleがこのデータを読むたびに画像取得に失敗している状態でした。
検索結果に写真つきで表示される可能性を、自ら下げてしまっていたことになります。

**→ 正しく存在する画像（1200×630px）に差し替えました。**

> この修正はテーマ側のため、**新しいテーマZIPのアップロードが必要**です。
> 手順は「10. 山口様にお願いする操作」をご覧ください。

### ② 中身が空のページが、検索エンジンに載る設定で公開されていた ─ 対応済み

`/パーキンソン病の方へ/` というページが、**本文1文字も入っていない状態**で
公開され、しかも**サイトマップでGoogleに「見に来てください」と案内していました。**

中身が空のページは、Googleから「品質の低いサイト」と判断される要因になります。

**→ 下書きに戻しました。** 対応後、以下を確認済みです。

- お客様がURLを開いても表示されない（404）
- サイトマップから自動的に外れた

> このページの本文は、実は `/for-parkinsons-disease/` の方に入っています。
> 中身が失われたわけではありませんのでご安心ください。

### ③ 旧デザイン時代のページ2本が、英語タイトルのまま残っている ─ 未対応

| URL | 検索結果に出るタイトル | 中身 |
|---|---|---|
| /for-parkinsons-disease/ | **for parkinson's disease** | 約3,500字。しっかりした解説 |
| /for-stroke/ | **for stroke** | 約5,400字。しっかりした解説 |

この2本は**中身が非常に良い**ページです。「パーキンソン病とは？」「一般的な治療」
「運動をする効果」など、海外の研究にも触れた読み応えのある内容が入っています。

**消すのはもったいないので、残して手直しすることをおすすめします。**

現在の問題点は3つです。

1. **検索結果のタイトルが英語**。日本語で探す方には何のページか伝わりません
2. **大見出し（H1）が1ページに2つ**あります。1つにすべきです
3. **サイト内のどこからもリンクされていない**孤立ページです

**→ ご承認いただければ、以下を実施します（テーマ改修は不要です）。**

- タイトルを「パーキンソン病の方へ｜ASPATH鹿児島」等の日本語に変更
- 説明文を設定
- コラムまたはフッターから導線を1本つなぐ

## 9. 反映を早める操作（山口様にお願いしたいこと）

Search Consoleに登録済みとのことですので、**再クロールを催促できます。**
数日待つより早く反映されることが多いです。

> ⚠️ Googleアカウントでのログインが必要なため、**私では実行できません。**

**手順**

1. https://search.google.com/search-console を開く
2. 上部の検索窓に `https://aspath-life.com/` を入力してEnter（「URL検査」）
3. 「**インデックス登録をリクエスト**」をクリック
4. 同じことを、下記のURLでも繰り返す

```
https://aspath-life.com/
https://aspath-life.com/about/
https://aspath-life.com/services/
https://aspath-life.com/contact/
https://aspath-life.com/campaign/
```

> 1日にリクエストできる件数に上限があります。**上の5本を優先**してください。
> 残りは自然に更新されます。

**あわせてお願いしたいこと**

Search Console → サイトマップ → 以下を送信（未送信の場合）

```
sitemap_index.xml
```

## 12. 率直な所感

**サイト内部の設定は、現時点でほぼ万全です。** タイトル・説明文・canonical・
構造化データ・サイトマップ・robots.txt、いずれも整っています。

そのうえで申し上げると、**「鹿児島 パーキンソン病 トレーニング」のような検索では、
Webサイトより先に地図の枠（Googleビジネスプロフィール）が表示されます。**

今後いちばん集客に効くのは、サイトの微調整よりも

1. **Googleビジネスプロフィールの整備**（写真・営業時間・口コミ）
2. **コラムを増やす**（お客様が検索する具体的な悩みに1記事ずつ答える）

この2つだと考えています。①はGoogleアカウントでのログインが必要なため
山口様の操作になりますが、手順書が必要でしたらお申し付けください。
