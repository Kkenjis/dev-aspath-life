## 1. 仮公開の前に必ず確認（これが本番前の最後の砦）

### 1-1. 表示の確認

- [ ] TOP・ASPATHについて・プランと料金・アクセス・お問い合わせ・よくある質問
- [ ] お知らせ一覧／キャンペーン記事
- [ ] コラム一覧／コラム3本
- [ ] プライバシーポリシー・特定商取引法・サイトマップ

**それぞれ PC・スマホ・タブレット**で開いて、崩れがないか見てください。

### 1-2. 動作の確認

- [ ] ヘッダーのメニューが全ページで同じ（**ハンバーガーが右端**にある）
- [ ] スマホメニューが開閉し、**公式LINEボタンが1行**に収まる
- [ ] TOPのお知らせに**「重要」バッジ**が出ている
- [ ] コラム記事の下に**「前の記事／次の記事」**が出る（端の記事は片側だけ）
- [ ] 全ページのリンクが**ステージング内**を指している（本番へ飛ばない）
- [ ] お問い合わせフォームから**テスト送信** → 山口様に届く／自動返信が届く
- [ ] 初回体験フォーム（限定URL）も同様にテスト送信

### 1-3. 検索避けが効いているか（重要）

- [ ] 設定 → 表示設定 → **「検索エンジンでの表示を許可しない」にチェックが入っている**

> ⚠ ここが外れていると、**仮のサイトが検索に載って本番と重複**します。SEO上のダメージになるので必ず確認してください。

## 2. 仮公開の手順

### 2-1. アクセス制限を外す

1. プラグイン → **LightStart（メンテナンスモード）** の設定を開く
2. **メンテナンスモードを OFF** にする
3. シークレットウィンドウで `https://aspath-life.com/development/` を開き、**サイトが表示される**ことを確認

> Basic認証をかけている場合は、そちらも解除します。

### 2-2. 共有する

山口様へ、この文面をそのままお渡しいただけます。

```
【ASPATH 新サイト 仮公開のご案内】

新しいサイトをご確認いただけるようになりました。
下記URLからご覧ください。

https://aspath-life.com/development/

※このURLはご案内した方のみが見られる状態です。
　検索しても出てきません。SNS等への掲載はお控えください。
※現在の aspath-life.com はこれまでどおり公開中で、
　今回の仮公開による影響はありません。
※スマートフォン・タブレット・パソコンのそれぞれで
　ご確認いただけますと幸いです。

お気づきの点は、画面のスクリーンショットを添えて
ご連絡いただけますと助かります。
```

## 3. 仮公開中の注意

- **SNSやLINEに貼らない**（拡散すると検索に拾われる可能性があります）
- お問い合わせフォームは**実際に動きます**。テスト送信は「テスト」と分かる内容で
- 仮公開中も、修正はこれまでどおり dev → テーマ再生成 → 上書きインストールで反映できます
