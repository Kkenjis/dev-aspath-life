## 5. キャッシュについて（重要）

このサイトは **Super Page Cache** という高速化プラグインが入っています。
**設定を変えただけでは、お客様に見える画面は変わりません。**

今回も設定保存後に古い内容が表示されたままだったため、キャッシュを消しています。

**手順：** 管理画面 → 左メニュー下の「Super Page Cache」 → 右上「**Purge Cache**」

> 何かを直したのに変わらない時は、まずこれを試してください。
> それでも変わらない場合は `★キャッシュが消えないとき.md` をご覧ください。

## 6. 今後の直し方（山口様向け）

説明文を書き換えたくなったとき。

1. 管理画面から、直したいページの編集画面を開く
2. 画面上部のツールバーにある「**SureRank**」のアイコンをクリック
3. 右側に出るパネルの「**Search Engine Description**」の欄を書き換える
4. パネル下の「**Save**」をクリック（「Data updated」と出れば成功）
5. **Super Page Cache → Purge Cache** を実行する

**書くときのコツ**

- 長さは**60〜160文字**。短すぎるとGoogleが勝手に本文から拾ってしまいます
- 頭の30文字くらいで内容が分かるように書く（スマホだとそこまでしか出ません）
- 「鹿児島」「パーキンソン病」など、探している方が打ち込む言葉を入れる
- 記号の使いすぎは避ける

## 7. 残っている課題

### ① 旧デザイン時代のページが3本、公開のまま残っています

| ID | URL | 状態 |
|---|---|---|
| 708 | /パーキンソン病の方へ/ | **中身が空**（本文10文字）。URLも日本語のまま |
| 702 | /for-parkinsons-disease/ | 旧デザインの本文が残っている |
| 712 | /for-stroke/ | 旧デザインの本文が残っている |

3本とも「検索エンジンに載せる」設定のままです。
特に**708は中身が空のページ**で、Googleに「品質の低いページ」と判断される要因になります。

**→ 山口様のご判断が必要です。** 対応案は3つ。

| 案 | 内容 | 向いている場合 |
|---|---|---|
| A（推奨） | 3本とも**下書きに戻す** | もう使わない。あとから中身を見返せる |
| B | **noindex**（公開したままGoogleに載せない） | 誰かに直接URLを教える予定がある |
| C | 削除 | 完全に不要。※元に戻せません |

### ② Search Console へのサイトマップ送信

`https://aspath-life.com/wp-sitemap.xml` を Search Console に登録すると、
Googleが新しいページを見つけるのが早くなります。
`aspathlife@gmail.com` でのログインが必要なため、**私では実行できません**。

### ③ Googleビジネスプロフィール

「鹿児島 パーキンソン病 トレーニング」のような検索では、
Webサイトより**地図の枠**が先に出ます。ここの整備が集客への効きが最も大きいです。
こちらもGoogleアカウントでのログインが必要です。

## 8. 効果の確認方法

Googleに反映されるまで**数日〜2週間程度**かかります。

- **Search Console → 検索結果のパフォーマンス**
  「クリック数」と「表示回数」を、今日を境に前後で比べてください
- 特に見ていただきたいのは**「表示回数」**です。説明文の改善は、
  まず表示回数より**クリック率（CTR）**に効きます
