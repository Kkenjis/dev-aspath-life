# ★ コラム3本の本文を新デザインに差し替える手順

作成日：2026年8月16日／所要 約25分（手作業で写すと60分以上かかる作業です）

---

## 0. 何をするか

いまステージングに入っているコラム3本は、**本番からインポートした旧サイトの本文**です。
これを **devで作り直した新デザインの本文**に差し替えます。

`★コラム本文_貼り付け用/` フォルダに、**WordPressにそのまま貼れる形**に変換した3つのファイルを用意しました。

| ファイル | 差し替え先の記事 | 見出し | 画像 |
|---|---|---|---|
| `taimentraining.html` | アスパススタジオでの対面トレーニング | 大5・小14 | 4点 |
| `onlineaspath.html` | アスパスのオンライントレーニングがおすすめ！ | 大6・小10 | 7点 |
| `column-parkinson.html` | パーキンソン病とアスパスの歩み方 | 大4・小3 | 4点 |

> ⚠ **新規作成しないでください。** 既存の記事を編集します。新しく作るとURLが
> `taimentraining-2` のように変わり、検索評価と既存リンクを失います。

## 1. 先に画像を登録する（10分）※必須

本文の画像は、**メディアライブラリに登録済みであること**が前提です。まだの場合は先にこちらを。

1. メディア → 新規追加
2. `★アップロード用_投稿画像18点/` の中身を**まとめてドラッグ&ドロップ**
3. 代替テキストは `★メディア登録_alt一覧_18点.md` からコピー

- [ ] 18点をアップロード済み
- [ ] メディアライブラリで `column-` と検索して**18点**出る

> 💡 いまメディアライブラリには `image-32` `image-25` のような**名前のない画像87点**が入っています。
> これは本番からインポートした際の添付ファイルです。**消さないでください**（旧記事が参照しています）。
> 新しく入れる18点は `column-` で始まるので、検索すれば区別できます。

## 2. 本文を差し替える（1本あたり5分）

記事ごとに、この5ステップを繰り返します。

1. 投稿 → 一覧から対象記事を開く
2. 右上の **⋮（オプション）** → **コードエディター** を選択
3. 表示されている中身を **すべて選択して削除**（`Ctrl+A` → `Delete`）
4. 用意したファイルの中身を**すべてコピーして貼り付け**
5. **⋮ → ビジュアルエディター** に戻して崩れがないか確認 → **更新**

- [ ] アスパススタジオでの対面トレーニング ← `taimentraining.html`
- [ ] アスパスのオンライントレーニングがおすすめ！ ← `onlineaspath.html`
- [ ] パーキンソン病とアスパスの歩み方 ← `column-parkinson.html`

> **コードエディターが見つからないとき**：右上の ⋮ をクリック → 「エディター」の項目に
> 「コードエディター」があります。ショートカットは `Ctrl + Shift + Alt + M` です。

### 画像が表示されないときは

貼り付けた本文の画像URLは、次の形を想定しています。

```
https://aspath-life.com/development/wp-content/uploads/2026/08/column-〇〇.webp
```

アップロードした月が違うと（例：9月にアップした）`/2026/09/` になり、画像が出ません。
その場合は**画像ブロックを選び直すだけ**で直ります。

1. 崩れている画像ブロックをクリック
2. ツールバーの **置換** → **メディアライブラリ** → 同じ名前の画像を選ぶ

またはメディアライブラリで1点URLを確認し、教えてください。**こちらで全ファイルのURLを一括修正**します。

## 4. 変換で行った調整（把握しておいてください）

devのHTMLをそのまま貼るのではなく、WordPress向けに整えています。

| dev側 | WordPress側 |
|---|---|
| 記事末尾のお問い合わせCTA（フォーム／LINEボタン） | **削除**。テーマ側が全記事共通で出すため |
| 記事末尾の「前の記事／次の記事」 | **削除**。テーマが自動生成するため |
| 分割禁止の指定（`.nw`）、PC専用改行 | **削除**。WordPress本文では不要 |
| 見出しの番号バッジ（`01` `STEP 1`） | **見出しテキストに統合**（例：`01 症状に特化した…`） |
| 囲み枠（`column-callout`） | **引用ブロック**に変換 |

見出しの数・画像の点数は**devと1つも違わないことを機械的に確認済み**です。
