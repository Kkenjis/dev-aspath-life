## 1. 編集画面を開く

```
https://aspath-life.com/wp-admin/
```

にログインし、左メニューから

```
固定ページ  →  「ASPATHについて」をクリック
```

---

## 2. 画面の見かた ── 「ブロック」という考え方

このページは、**文章のかたまり（ブロック）が上から順に並んでいる**構造です。

```
┌────────────────────────┐
│ ASPATHの由来            │ ← 見出しのブロック
├────────────────────────┤
│ A S P A T H の一覧      │ ← 飾りのブロック（グレーで表示。触りません）
├────────────────────────┤
│ 「アス＝明日へ…」        │ ← 文章のブロック
├────────────────────────┤
│ ロゴには、いくつもの…    │ ← 文章のブロック
└────────────────────────┘
```

**文字の上をクリックすると、そのブロックが選ばれて枠が付きます。**
枠が付いたら、あとはWordやメールと同じように書き換えるだけです。

---

## 3. 文章を直す

```
① 直したい文章をクリック
② カーソルが出るので、いつもどおり書き換える
③ 右上の【更新】
```

**それだけです。** 保存も自動ではありませんので、**必ず【更新】を押してください。**

### 途中で改行したいとき

| したいこと | 押すキー |
|---|---|
| 段落を分ける（間があく） | **Enter** |
| 同じ段落の中で改行（間があかない） | **Shift ＋ Enter** |

### 文字を太くしたいとき

太くしたい文字を**マウスでなぞって選び**、上に出るメニューの **B** をクリックします。

---

## 4. 写真を差し替える

写真をクリックすると、上にメニューが出ます。

```
① 写真をクリック
② 出てきたメニューの【置換】
③ 「アップロード」で新しい写真を選ぶ
④ 右上の【更新】
```

> **写真は横1200ピクセルくらいがおすすめです。**
> スマホで撮ったままの大きな写真でも表示はされますが、ページが重くなります。

---

## 5. 触らない部分の見分けかた

**クリックしても文字が編集できず、代わりにHTMLの記号が出てくる箱**があります。

```
<div class="origin-hero"> …
```

これは**飾りの部分**です。デザインが崩れないように固めてあります。
このページでは次の5か所です。

| 場所 | 何が入っているか |
|---|---|
| ASPATHの由来のすぐ下 | A・S・P・A・T・H の一覧 |
| ASPATHの特徴のすぐ下 | 特徴3つのカード（写真つき） |
| 「自分らしい人生」の帯 | 大きな背景写真の部分 |
| 4つの理念 | 図 |
| 各章の写真とその説明文 | 図とキャプション |

> **ここを直したいときは、これまでどおりご連絡ください。**
> 触ってしまっても【更新】を押さなければ元のままです。

---

## 6. 保存する前に見た目を確認する

```
右上の【プレビュー】 → 「新しいタブでプレビュー」
```

**お客様に見える形**で確認できます。問題なければ【更新】を押してください。

---

## 7. やらないほうがよいこと

| | 理由 |
|---|---|
| **ブロックごと削除する** | 飾りの箱を消すとデザインが崩れます。文字だけ書き換えてください |
| **貼り付けで書式を持ち込む** | Wordからコピーすると余計な書式が入ります。**Ctrl + Shift + V**（書式なし貼り付け）を使ってください |
| **見出しの大きさを変える** | 「見出し2」「見出し3」の設定は変えないでください |

---

## 8. 間違えたときは

| こんなとき | どうする |
|---|---|
| **書き換える前に戻したい**（更新前） | 左上の【↩】を何回か押す |
| **更新してしまった** | 右側「投稿」タブ →「リビジョン」→ 前の状態を選んで復元 |
| **表示が崩れた** | 何も操作せずご連絡ください。**すぐ元に戻せます** |
| **画面が真っ白になった** | 同上。データは消えていません |

> **「リビジョン」に過去の状態が全部残っています。** 元に戻せなくなることはありません。

---

## 9. 直した後、サイトに反映されないとき

```
① 5分ほど待ってから、もう一度ページを開く
② それでも変わらなければ、Ctrl を押しながら F5
③ URLの最後に ?v=2 を付けて開く（例：https://aspath-life.com/about/?v=2）
```

**②③で新しくなっていれば、更新自体は成功しています。**
時間をおけば他の方にも反映されます。
