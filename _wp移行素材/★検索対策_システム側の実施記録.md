# ★ 検索対策（SEO）── システム側の実施記録

実施：2026年8月24日　／　**テーマのアップロードで反映されます**

---

## 1. 実施前に見つかった問題

本番15ページを実測した結果です。

| # | 問題 | 影響 |
|---|---|---|
| 1 | **構造化データが全ページで消えていた** | 「鹿児島の何のお店か」が検索エンジンに伝わっていない |
| 2 | **TOPに `h1` が無い** | ページの主題が伝わりにくい |
| 3 | **説明文が7ページで空** | 検索結果の紹介文が本文の切れ端になる |
| 4 | **SNS共有画像がLINEのボタン画像** | 共有したときASPATHのサイトに見えない |

### 1が起きた理由

移行時、テンプレート化していたのは `<main>` の中だけでした。
`HealthClub`（お店情報）と `FAQPage`（よくある質問）の構造化データは
**`<head>` に置かれていたため、丸ごと落ちていました。**

---

## 2. 実施した内容（すべてテーマ側）

### ① 構造化データの復活

`index.html` の `<head>` にある JSON-LD をビルド時に取り出し、
`functions.php` から出力するようにしました。

| 種類 | 出力先 | 内容 |
|---|---|---|
| `HealthClub` | TOPページ | 店名・所在地・提供サービス・料金帯など |
| `FAQPage` | よくあるご質問 | 質問6件と回答 |

> **見つからない場合はビルドを止めます。**
> 同じ取りこぼしが二度と起きないよう、`build_wp_theme.py` に検査を入れました。

### ② TOPの `h1`

```
変更前： <p class="hero-spec">鹿児島初｜パーキンソン病専門 トレーニングスタジオ</p>
変更後： <h1 class="hero-spec">…（同じ文言）…</h1>
```

**見た目は変わりません。** スタイルはクラスで当たっているためです。

### ③ 説明文が無いページへの自動補完

本文が空のページ（テンプレートで作っているページ）はSEOプラグインが
説明文を作れません。テーマ側で用意しました。

```
コラム一覧 ／ お知らせ一覧 ／ アクセス ／ よくある質問
プライバシーポリシー ／ 特定商取引法 ／ サイトマップ
```

### ④ SNS共有画像の修正

`og:image` が **LINEの「友だち追加」ボタン画像**を指していました。
SEOプラグインが「ページ内の最初の画像」を自動で選んだためです。

**自サイト外を指している場合は、自社の画像に差し替える**ようにしました。
画像（1200×630）は**テーマに同梱**しているので、アップロード作業は不要です。

## 3. 二重出力を避けるしくみ

SEOプラグイン（SureRank）と競合しないよう、次の方式にしています。

```
wp_head の最初（優先度0）   … <head> の出力をためはじめる
wp_head の最後（優先度999） … たまった内容を見て、
                              「無いものだけ」を足してから出力する
```

**プラグイン側で設定した場合は、そちらが優先されます。**
将来 SureRank に説明文を入れても、二重にはなりません。

## 4. 反映の手順

```
1. 外観 → テーマ → 新規追加 → テーマのアップロード
2. aspath-theme.zip（v1.1.20260824 以降）
3. 「既存のものを置き換える」
4. Super Page Cache → Purge Cache
```

### 反映後に確認すること

| 確認 | 方法 |
|---|---|
| 構造化データ | [リッチリザルトテスト](https://search.google.com/test/rich-results) に `https://aspath-life.com/` を入力 |
| TOPの `h1` | ページを開いて `Ctrl+U` → `<h1` を検索 |
| 説明文 | `/access/` などを開いて `Ctrl+U` → `name="description"` を検索 |
| SNS共有画像 | LINEで自分宛にURLを送る |
