## 2. なぜ「図形だけ」なのか

タブのアイコンは **16px**、検索結果でも **16〜24px** でしか表示されません。
その大きさでは「ASPATH」の文字はつぶれて読めず、**マークまで小さくなって**しまいます。

図形だけを使えば、同じ大きさでも形がはっきり残ります。
ロゴの一部なので**印象は変わりません。**

> 比較は `★サイトアイコン素材/★比較プレビュー.png` をご覧ください。
> 実際の表示サイズで並べています。

**背景を白にしている理由**：透過のままだと、ダークテーマのブラウザで
紺色が背景に沈んで**ほとんど見えなくなる**ためです。

## 3. 設定手順（5分）

```
1. https://aspath-life.com/wp-admin/ にログイン
2. 外観 → カスタマイズ
3. 「サイト基本情報」をクリック
4. 「サイトアイコン」の【画像を変更】
5. ファイルをアップロード → ★これをアップロード_サイトアイコン_512.png を選ぶ
6. 切り抜き画面が出たら、そのまま【切り抜き】（余白は調整済みです）
7. 右上の【公開】
```

**確認**

```
8. キャッシュを削除（Super Page Cache → パージ）
9. Ctrl + F5 で再読み込み
10. タブの左が新しいアイコンになっていればOK
```

> **すぐ変わらない場合はブラウザのキャッシュです。**
> ファビコンは特に強く保存されます。別のブラウザか、
> `https://aspath-life.com/favicon.ico` を直接開いて確認してください。

## 4. 検索結果に反映されるまで

**Googleが再訪問するまで反映されません。数日〜数週間かかります。**

早めたい場合：

```
Search Console → 上部の検索窓に https://aspath-life.com/ を入力
→ 「インデックス登録をリクエスト」
```

**Googleがアイコンを使う条件**（今回の画像はすべて満たしています）

- 正方形であること ✅
- 48pxの倍数が望ましい ✅（192×192を出力します）
- サイト全体で同じアイコンであること ✅
- robots.txtでブロックされていないこと ✅

## 5. 【重要】あわせて直したほうがよい問題

**サイトアイコンを調べる過程で、別の不具合が見つかりました。**

### SNSで共有すると「LINEのボタン画像」が出ます

いま `https://aspath-life.com/` をLINE・Facebook・Xに貼ると、
サムネイルが **LINEの緑の「友だち追加」ボタン**になります。

```
現在の設定
  og:image → https://scdn.line-apps.com/n/line_add_friends/btn/ja.png
             ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
             LINE社のボタン画像。ASPATHとは無関係
```

**原因**：SEOプラグインの共有画像が未設定のため、
**ページ内の最初の画像**（＝LINEボタン）が自動で選ばれています。

**影響**：山口様やお客様がLINEでサイトを紹介したとき、
**ASPATHのサイトだと分からない見た目**になります。

### 差し替え用の画像も作成済みです

```
_wp移行素材/★サイトアイコン素材/★SNS共有画像_ogp_1200x630.png
```

**設定手順**

```
1. SEOプラグインの設定 → ソーシャル（SNS）
2. 「デフォルトのOGP画像」に上記をアップロードして指定
3. 保存 → キャッシュ削除
4. LINEで自分宛にURLを送って確認
```

> LINEはサムネイルを保存するため、**すぐには変わらないことがあります。**
> その場合はURLの末尾に `?1` を付けて試すと新しい画像で確認できます。

### 構造化データのロゴも404です

```
"logo": https://aspath-life.com/wp-content/uploads/2026/05/cropped-ASPATH-ロゴ完成.png
        → ❌ 404（存在しないファイル）
```

**サイトアイコンを設定し直すと、この参照も自動で新しいものに更新されます。**
手順3を行えば同時に解消します。
